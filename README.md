## 🌟 المميزات الرئيسية (Key Features)

### 1. 🎨 توافق كامل مع مصمم المظهر (Theme Designer)
* تحكم كامل في الألوان (الرئيسية، الخلفيات، النصوص، الروابط).
* تخصيص أبعاد الخطوط ونوع الخطوط لجميع العناصر.
* التحكم في أبعاد وعرض الشعار في الهيدر والفوتر (`logoWidth`, `logoHeight`, `footerLogoWidth`, `footerLogoHeight`).
* تبديل تفعيل وتعطيل الميزات المتقدمة مباشرة بنقرة زر دون تعديل كود XML.

### 2. 🖼️ لوجو الفوتر والهيدر من التنسيق (Layout Image Widgets)
* **رفع الشعار مباشرة من جهازك**: يمكنك رفع صورة الشعار الخاصة بموقعك من تبويب **التنسيق (Layout)** في بلوجر لكل من الهيدر والفوتر عبر أداة صورة رسمية (`type='Image'`).
* **نظام البديل الذكي (Smart Fallback)**: في حال عدم رفع صورة، يعرض القالب الشعار كنص أنيق مع نقطة TekMax المميزة تلقائياً دون أي تشوه.

### 3. ⚡ سرعة وأداء قياسي (100/100 Core Web Vitals)
* كود نظيف وخفيف بدون مكتبات خارجية ثقيلة (Vanilla JavaScript ES2025).
* تحميل متقدم وأولوية معالجة للصور (`fetchpriority="high"`, `decoding="async"`, `loading="lazy"`).
* تسريع خطوط جوجل والاتصال المسبق (Preconnect & DNS-Prefetch).

### 4. 🛠️ ميزات المقال المتطورة (Modular Post Features Engine)
* **شريط تقدم القراءة (Reading Progress Bar)**: يتابع تقدم القارئ في المقال بأناقة.
* **فهرس المقال التلقائي (Auto Table of Contents - TOC)**: توليد عناوين المقال التفاعلية مع دعم الطي والفتح.
* **مكبر ومصغر حجم الخط (Font Size Resizer)**: للتحكم في حجم خط القراءة (+ / -).
* **عارض الصور المكبر (Lightbox)**: تكبير الصور داخل المقال بشاشة كاملة عند النقر.
* **صندوق الكاتب والمقالات ذات الصلة**: تصميم بطاقات عصري وجذاب.
* **أزرار المشاركة والطباعة**: مشاركة فورية على وسائل التواصل أو طباعة المقال بتنسيق نظيف.

### 5. 💻 صندوق الأكواد البرمجية الاحترافي (GitHub Code Box)
* تسليط الضوء التلقائي على الأكواد (Syntax Highlighting).
* زر نسخ الكود بنقرة واحدة مع إشعار نجاح.
* أرقام أسطر تلقائية بدون فراغات.
* زر تحميل الكود كملف برمجي.

### 6. 🌓 الوضع الليلي الفوري (Native Dark Mode)
* تبديل سلس وسريع بين الوضع الفاتح والداكن.
* حفظ تفضيل الزائر محلياً في المتصفح (`localStorage`).

## 📥 دليل التثبيت (Installation Guide)

1. حمّل ملف القالب [`BlogTekMax Pro(2).xml`](BlogTekMax%20Pro(2).xml) أو [`BlogTekMax Pro.xml`](BlogTekMax%20Pro.xml).
2. توجّه إلى لوحة تحكم مدونتك في **Blogger** > **المظهر (Theme)**.
3. انقر على السهم بجانب زر **تخصيص (Customize)** > اختر **استعادة (Restore)**.
4. اختر ملف القالب المرفوع واضغط **حفظ (Save)**.
5. استمتع بالقالب الجديد فائق السرعة!

---

## ⚙️ تخصيص القالب من التنسيق (Layout Customization)

* **شعار الهيدر**: `التنسيق > رأس الصفحة (Header) > تعديل` واضغط اختيار ملف لرفع لوجو موقعك.
* **شعار الفوتر**: `التنسيق > الفوتر > شعار الفوتر (Footer Logo) > تعديل` وارفع لوجو الفوتر المفضل لديك.
* **القائمة الرئيسية**: `التنسيق > القائمة الرئيسية (Main Menu)` لإضافة روابط وتصنيفات موقعك.
* **مواقع التواصل**: `التنسيق > مواقع التواصل (Social Links)` لوضع روابط حساباتك الاجتماعية.
